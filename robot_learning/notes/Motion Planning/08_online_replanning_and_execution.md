## 用时间轴判断还能接什么

假设 policy chunk 的 waypoint 间隔是 50 ms，带有相对观测时刻的执行时间。第一个 waypoint 对应 $t=0$。新 chunk 在 120 ms 返回，预计控制线程在 130 ms 可切换。

| 事件 | 时刻 |
|---|---:|
| 观测与首个目标时刻 | 0 ms |
| 第二、第三目标时刻 | 50、100 ms |
| 推理完成 | 120 ms |
| 预计轨迹交接 | 130 ms |
| 第一个尚未过期的 waypoint | 150 ms |

交接时某轴还差 $0.06$ rad，而速度上限是 $1$ rad/s。剩下 20 ms 内位移至多 $0.02$ rad。即使 150 ms 点的语义仍有效，也无法按原定时间追上。可根据任务重选后续目标、调整定时或重新规划。对夹爪闭合、接触建立等事件，要确认重定时后仍在正确阶段发生。源动作若是 delta 或下一个控制步的目标，应先按原定义解码和对时。[第 13 课 动作与控制接口](../13_action_and_control_interfaces.md)

## 从哪个状态交接

- **参考状态。** 用旧的时间参数化轨迹在切换时刻求出 $(q_d,\dot q_d,\ddot q_d)$。跟踪偏差小、参考符合当前环境时，可用该边界状态构造连续桥接。
- **实际状态。** 需要验证动力学和碰撞时，用状态估计或按延迟预算预测到交接时刻，并考虑误差。实测与参考相差较大时，直接复制任一侧都可能产生问题。应根据偏差、跟踪模式与可控性设计重接，必要时回到可验证的制动或保持行为。
- **新目标状态。** 按时间戳与任务阶段选下一可用目标，说明它的 $q,v,a$ 来自明确边界条件、估计还是控制接口。用 MP5 的五次 Hermite 或 MP6 的 OTG 连接后，查段内碰撞、极值和到达时间。
- **轨迹发布。** 控制线程以自己的时基采样同一个已确认版本，规划线程发布带明确生效时刻的参考。过期或不可行时按已定义的处理方式执行。制动轨迹本身也要检查当前速度和空间余量。

桥接即使 $C^2$，仍要查 jerk 限幅。线性位置插值可能在 waypoint 处产生速度跳变。单段 SLERP 的角速度沿固定旋转轴，相邻段的角速度仍可能不匹配。[MP5 五次插值](05_point_to_point_trajectories.md)

## 如何把问题定到一层

| 现象 | 先保留哪些证据 | 对照实验 |
|---|---|---|
| 规划输出偶尔碰撞 | 原始边、平滑段、场景版本、最小 clearance | 保持场景固定，分别验证搜索路径和后处理路径 |
| 参考在拐角无停顿，跟踪跟不上 | 参考与实测 $q,\dot q$、加速度和力矩饱和 | 同一几何路径降低定时速率，比较误差和峰值力矩 |
| 每次换 chunk 都抖 | 实际交接时刻两侧参考、桥接段的导数、实际状态 | 固定同一组新旧目标，比较直接替换和有边界约束的桥接 |
| 接触时力峰上升 | wrench、参考和实测 $\ddot q$、接触与 gripper 事件时刻 | 在相同帧和时间口径下比较进入接触前后的惯性与外力响应 |
| 输出频率高但反应慢 | 观测、推理返回、提交和实际执行的时间戳 | 分别量化观测到执行的延迟和每环节的更新率 |

**接回 FP2/VLA。** 时间或阶段对齐决定接哪段，插值决定中间参考怎么变，反馈控制决定实际运动与接触。复盘时可用你的第 13 课对照论文描述的五次样条和所读 peg 代码的 linear + SLERP，再说明各自的导数连续性如何检查。1 kHz 输出网格只是轨迹采样口径，观测和新参考的时效要另外测量。[FP2 源码复盘](../03d_fp2_source_architecture_and_training.md) · [第 13 课多速率与插值](../13_action_and_control_interfaces.md)

**自测。** 给一条刚结束规划的轨迹列出发布前的三个检查。可以依次说切换时的状态和时间是否对齐、桥接及新路径的约束是否通过、截止时间与任务事件是否仍可满足。再用一条指标说明如何从日志重现失败。
