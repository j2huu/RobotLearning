# Transformer 面试题卡：40 题

[目录](README.md) · [速查表](cheatsheet.md) · [原 ML 40 题](../interview_drill.md)

每题先独立口述 60–90 秒，再看答案要点。评分：0=错误；1=定义；2=公式/shape/例子；3=能说明假设、反例与验证方法。先记录错因，阅读次数不计作掌握。这里是新增专题 40 题，原 ML 40 题仍保留。

## T1：Attention 基础

1. **为什么 Q/K/V 要分开？** Q/K 决定匹配，V 携带内容，不同投影提供表达自由。追问：只改 V，权重会变吗？答案：固定 Q/K 时不变；改原始 X 时可能三者一起变。
2. **为什么除以 $\sqrt{d_h}$？** 在独立零均值单位方差假设下，内积方差随 $d_h$ 增长。追问：训练后该假设一定成立吗？不一定，这是尺度动机。
3. **手算 `[0,ln3]` 对 `[2,10]` 的 attention。** 权重 `[1/4,3/4]`，输出 8；屏蔽第二项输出 2。追问：softmax 后乘零为什么不同？剩余权重未重新归一化。
4. **多头为何不等于多个完整宽度模型？** 通常总 d 拆成 H×dh，各头独立匹配再投影；固定 d 时参数约 $4d^2$。追问：head 更多总更好吗？不是，每头宽度变小且可能冗余。
5. **推导 score 梯度。** $\partial L/\partial s_j=\alpha_j g^T(v_j-y)$。追问：为什么 score 梯度和为零？对所有 logits 加同一常数不改变 softmax。

## T2：完整结构

6. **画完整 Pre-LN block。** LN→attention→残差，再 LN→FFN→残差；attention 内含 O 投影。追问：最终 stack norm 在哪？查架构，不能只据单块推断。
7. **FFN 在 token 间交换信息吗？** 标准 FFN 逐 token 共享参数，不混 token 轴。追问：为什么要非线性？否则两层线性可合并。
8. **LayerNorm 对哪些轴统计？** `LayerNorm(d)` 对每个 token 的 d 个 features 归一化。追问：若误跨 token 呢？可能引入非预期依赖甚至未来泄漏。
9. **RMSNorm 与 LayerNorm 差别？** RMSNorm 不减均值，以均方根缩放；不保证输出零均值。追问：`[1,3]` 的结果？LN 约 `[-1,1]`，RMS 约 `[0.447,1.342]`。
10. **Encoder、decoder-only、seq2seq decoder 有何不同？** 分清输入可见性、self/cross 子层及训练目标。追问：decoder-only 必有 cross 吗？没有这个必然关系。

## T3：位置与顺序

11. **没有位置编码的 attention 是置换不变吗？** 无位置结构时通常是置换等变；对称池化后才可能不变。追问：加 causal mask 呢？原证明假设失效。
12. **绝对位置、relative bias、RoPE 加在哪？** 输入表示、scores、Q/K 的旋转。追问：三者都等价吗？不等价，归纳偏置和计算位置不同。
13. **手推 RoPE 的相对位移。** $(R(i\theta)q)^T R(j\theta)k=q^T R((j-i)\theta)k$。追问：相同距离就相同 attention？不，内容 q/k 还不同。
14. **左 padding 如何影响位置？** 物理列号和逻辑 position ID 不一定相同。追问：怎么验证？比较单条与 padded batch 对应有效位置输出。
15. **RoPE 能算长序列就能泛化吗？** 数学可计算不保证训练长度外的理解能力。追问：还测什么？任务质量、检索、长短依赖和资源消耗。

## T4：Mask

16. **Causal mask 为什么允许对角线？** 当前位置输入是 next-token 任务的已知历史。追问：不 shift，只去对角线能修复吗？残差仍携带原 token，不能。
17. **Padding、attention、loss mask 能互相替代吗？** 不能，分别涉及有效输入/读取关系/监督范围。追问：prompt 不算 loss 还能被回答读吗？可以。
18. **MHA 和 SDPA 的 bool mask 有何陷阱？** MHA True 禁止，SDPA True 允许；形状接口也不同。追问：怎么避免？内部统一 allowed，再在边界转换并做数值反例。
19. **所有 keys 都被屏蔽怎么办？** 有效 query 应报错或修正契约；无效 query 在计算前安全处理并排除后续使用。追问：-1e9 能修好吗？可能产生错误均匀读取，不能通用修复。
20. **直接边被禁为何还泄漏？** D→P→C 两层可达。追问：只测一层够吗？不够，还需跨层与预处理依赖检查。

## T5：训练与生成

21. **训练并行是否违反自回归？** 真实历史已知，各位置通过 mask 保持合法条件；层之间仍串行。追问：推理为何不同？新 token 未知，通常需顺序采样。
22. **写 input/label 对齐。** `[BOS,A,B]` 对 `[A,B,EOS]`。追问：封装内部 shift 怎么处理？不能外部再 shift，先检查接口。
23. **Masked CE 为什么要除有效 token 数？** 固定 padded 分母会让长度分布改变梯度尺度。追问：一个有效 token 也没有呢？明确跳过或报错。
24. **Teacher forcing 的收益与局限？** 并行最大似然训练；真实历史与模型历史的分布可能不同。追问：这是不是答案泄漏？合法历史不是未来答案。
25. **Temperature、top-k、top-p 与 beam search？** 前三者调整分布/采样范围，beam 搜索多个前缀。追问：能修错误 mask 吗？不能；高 likelihood 也不等于事实正确。

## T6：Cache

26. **为什么缓存 K/V 不必缓存旧 Q？** 新输出只需当前 Q 读取历史 K/V。追问：每层 K/V 相同吗？不，各层输入与投影不同。
27. **从因果性证明 cache 可复用。** 旧位置不能读新增位置，逐层归纳旧 hidden 不变。追问：双向 encoder 呢？新增输入可能改变旧表示。
28. **已有3个 token，再处理2个，写 mask。** 两行 `11110`、`11111`。追问：局部 tril 的错误？屏蔽合法历史，结果不同。
29. **估算 KV 显存。** $2LBNH_{kv}d_hs$。追问：这个数包含什么？只含理想 K/V 存储，不含模型、临时量和分配开销。
30. **Cache 等价性怎么测？** 固定模式、位置、参数等，对比 full 与 incremental 对应输出。追问：beam 重排呢？必须同时重排 cache 的样本归属。

## T7：效率

31. **Transformer 哪些项是 N²？** Dense pairwise attention 的算术和显式 score 矩阵；投影/FFN 对 N 线性。追问：短序列一定 attention 占主导吗？不一定。
32. **MHA/MQA/GQA 怎么区别？** KV head 数为 H/1/G，Q heads 可保持 H。追问：KV 少4倍总延迟少4倍吗？还有其他瓶颈。
33. **FlashAttention 是否近似 attention？** 标准 dense 版本保持数学目标，优化 IO/存储，浮点舍入可能不同。追问：算术复杂度变线性了吗？没有普遍如此。
34. **Local attention 为什么不是免费加速？** 删掉远距离边，改变可达信息和模型语义。追问：多层能否补回？可扩大感受野，但路径长度与表达不同。
35. **KV cache 与 activation checkpointing？** 前者推理复用历史 K/V，后者训练以重算换激活存储。追问：能否用后者解决所有 decode KV 占用？不是同一个对象。

## T8：Coding 与系统

36. **`view(B,H,N,dh)` 为何可能错？** 原投影布局需先拆为 `[B,N,H,dh]` 再交换轴。追问：只检查 shape 够吗？要检查元素映射与数值结果。
37. **未来扰动测试通过就绝对安全？** 只能支持被测输入和实现；退化权重也会无差异。追问：如何增强？多个输入、正向错误对照、多层和全输入链路审查。
38. **动作块内部是否必须 causal？** 看目标；AR 通常要，joint diffusion/flow 可以双向候选读取。追问：未来真实传感器可直接作为条件吗？部署不可得时不可以。
39. **FP2 context cache 与 AR KV cache？** 一个是压缩条件表示，另一个是各层 K/V 复用。追问：都能自动更新旧观测吗？不能，需新输入及依赖更新。
40. **设计一个 Transformer 推理优化实验。** 明确 workload、baseline、正确性、prefill/decode 分项、显存和质量。追问：吞吐更高是否单请求更快？排队/batching 可能增加延迟。
