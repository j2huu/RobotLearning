## 一条链记住七课

```text
区分关节空间、任务空间与动作空间
 → 坐标系说清楚
 → FK：关节位置到末端位姿
 → IK：目标末端位姿到关节位置
 → Jacobian：关节速度到末端速度
 → 动力学：力矩与加速度
 → 控制：目标、实际状态与执行命令形成闭环
```

| 关系 | 最小公式 | 容易混淆的点 |
|---|---|---|
| 构型、任务与动作 | $q$ 描述关节位置，$p=f(q)$ 描述末端位置，$a_t\in\mathcal A$ 由策略接口定义 | 相同的笔尖任务可用末端目标、关节目标或力矩执行。先查动作分量的含义和单位 |
| 坐标变换 | ${}^Ap={}^AR_B{}^Bp+{}^At_B$ | 同一个点，换 frame 后坐标变化 |
| FK | $T=f(q)$ | 需要几何模型；不由质量决定 |
| 2R FK | $x=l_1\cos q_1+l_2\cos(q_1+q_2)$；$y=l_1\sin q_1+l_2\sin(q_1+q_2)$ | 第二杆绝对角度是 $q_1+q_2$ |
| IK | 求 $q$ 使 $f(q)$ 满足目标 | 可以无解、多解；位置与完整位姿任务不同 |
| 速度 | $\dot p=J(q)\dot q$ | 本专题为末端点线速度；J 是局部关系 |
| 力映射 | $\tau_{ext}=J^Tf_{ext}$ | 明确外力方向、frame 和参考点 |
| 动力学 | $M\ddot q+h+g+\tau_f=\tau$ | 此式先不含接触；静止也可能需要 torque |
| 关节控制 | $\tau=K_p(q_d-q)+K_d(\dot q_d-\dot q)+g$ | 位置目标还需 controller 和轨迹 |

## 两个小模型，别混零点

- B2–B4：平面 2R，$q_1$ 从 x 轴量，$q_2$ 相对第一杆量，长度 1 m；只讲几何，不求这台两连杆的重力模型。
- B5：单摆，q 从竖直向下量，$I=0.5$、$m=1$、$l_c=0.5$；重力项是 $4.9\sin q$ N·m。
