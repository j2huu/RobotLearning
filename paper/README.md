# 论文原文

本目录集中存放论文 PDF，目前共 22 篇。论文标题、优先级、主题与课程用途见 [论文索引](../robot_learning/resources/paper_index.md)。

保留原始论文文件名；课程笔记和索引通过相对链接引用本目录。新增论文时：

1. 将 PDF 放到 `paper/`。
2. 在论文索引中记录标题、来源、版本、主题与阅读用途。
3. 在相关课程笔记中添加阅读链接。
4. 用 Git 提交 PDF 和索引/笔记的对应更新。

论文阅读笔记放到 [robot_learning/notes](../robot_learning/notes/README.md)，代码实验放到 [robot_learning/labs](../robot_learning/labs/README.md)。
